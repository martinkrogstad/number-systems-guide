
# Number Systems Guide

An educational website explaining hexadecimal, octal, and other number systems used in computing.

## About the Project

This project was created while studying Cyber Security at Noroff.

The website explains how hexadecimal and octal number systems work, with practical examples from networking, programming, and Linux file permissions.

## Features

- Three interconnected HTML pages
- Introduction to binary, decimal, octal, and hexadecimal
- Number system comparison table
- Interactive decimal-to-binary, octal, and hexadecimal converter
- Examples of Linux file permissions (`chmod 755`)
- SVG diagrams illustrating number systems
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG
- Apache2 (local hosting on Linux Mint)
- Visual Studio Code

## Pages

- `index.html` – Introduction and number base converter
- `hexadecimal.html` – Hexadecimal explanations and examples
- `octal.html` – Octal explanations and Linux permissions

## Running Locally

Download or clone this repository and open `index.html` in a web browser.

The website uses HTML, CSS, and JavaScript and does not require a backend.
