Understanding Number Systems

Learn how hexadecimal and octal numbers are used in computing, networking, and cybersecurity.

What Are Number Systems?

Computers use different number systems to represent and process information. Each number system has a base, which determines how many different digits it uses.

Common Number Systems

  • Binary (Base 2) - Uses digits 0 and 1.
  • Octal (Base 8) - Uses digits 0 to 7.
  • Decimal (Base 10) - Uses digits 0 to 9.
  • Hexadecimal (Base 16) - Uses digits 0 to 9 and A to F.
